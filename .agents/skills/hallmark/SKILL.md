# Hallmark Design Skill (Anti-AI-Slop Frontend Design)

Skill này hướng dẫn quy trình thiết kế và xây dựng giao diện người dùng (Frontend UI) độc đáo, hiện đại, tuyệt đối **KHÔNG SỬ DỤNG GIAO DIỆN AI-SLOP** (giao diện generic, rập khuôn kiểu AI mặc định).

## 1. Nguyên tắc Anti-AI-Slop
1. **Tránh màu rập khuôn AI:** Không sử dụng màu tím mộng mơ/xanh lam nhạt mặc định AI (purple/indigo gradient on dark background). Hãy chọn bảng màu curated hài hòa (HSL custom hoặc Palette có phong cách riêng).
2. **Typography Hiện Đại:** Sử dụng Google Fonts (Inter, Outfit, Plus Jakarta Sans, Fira Code cho code) thay vì font mặc định của trình duyệt.
3. **Chủ đề thiết kế đa dạng (21 Themes):** Áp dụng theme phù hợp cho từng sản phẩm:
   - Modern Dark Glassmorphic
   - Sleek Editorial / Magazine
   - Minimalist Swiss Grid
   - High-contrast Industrial / CAD Mode
   - Neo-brutalist / Clean Tech
4. **Tránh Placeholder Ảo:** Mọi hình minh họa, mockup phải sắc nét, có ý nghĩa, sử dụng công cụ tạo ảnh hoặc SVG chuẩn.
5. **Dynamic Interactions & Micro-animations:** Bổ sung hiệu ứng mượt mà khi hover, active, transition để giao diện sống động và cao cấp.

## 2. Các Lệnh / Thao tác Chính
- **Audit UI:** Kiểm tra và loại bỏ các thành phần rập khuôn AI.
- **Redesign UI:** Thiết kế lại toàn bộ layout và màu sắc theo theme độc đáo.
- **Study & Benchmark:** Phân tích ảnh chụp màn hình / URL để lấy cảm hứng thiết kế UI chuyên nghiệp.
